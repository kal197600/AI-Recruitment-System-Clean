# RecruitAI Frontend

Responsive React + Vite interface for the AI Recruitment System.

## Run locally

```bash
cd frontend2
npm install
npm run dev
```

The Vite development server will print the local URL, normally `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

## Main design improvements

- Responsive desktop sidebar and closable mobile navigation drawer
- Sticky adaptive header with global search and account controls
- Full-width application shell without the original Vite width restriction
- Mobile-friendly dashboards, toolbars, dialogs, data grids, and action groups
- Refined typography, spacing, cards, report exports, and email-import workflow
- Consistent recruitment-focused visual identity across all pages

## Main source folder

The enhanced interface is in `frontend2/src`.
