# Design Update Summary

The enhanced interface is located in `frontend2`.

## Updated areas

- Application layout and responsive breakpoints
- Desktop and mobile navigation
- Sticky top bar and global search placement
- Dashboard KPI cards, charts, lists, and quick actions
- Candidate, job, and application toolbars and data grids
- AI screening page width behavior
- Reports export cards
- Email import workflow presentation
- Mobile dialog sizing and page headers
- Global CSS reset, background, spacing, and typography

## Start the frontend

```bash
cd frontend2
npm install
npm run dev
```
